# 📦 ApnaBudget - Pre-Release v0.0.7 (Beta)

Welcome to the **pre-release** of **ApnaBudget: Empowering Your Financial Future Through Smart Budgeting**.

This APK is intended for testing and feedback purposes only. It may contain bugs and incomplete features. Your feedback is crucial to help us improve the final product!

---

## 🔍 What's Included

- 🔐 **Login & Registration**
- 📩 **Automatic Transaction Fetching from SMS**
- 🧾 **Manual Transaction Entry**
- 🖼️ **Image-Based Transaction Input (Beta)**
- 🗂️ **Transaction Categorization**
- 📊 **Basic Spending Summary**

---

## 📱 How to Install

1. Download the APK from the github release.
2. Make sure installation from unknown sources is enabled in your phone’s settings.
3. Install the APK and launch ApnaBudget.
4. Start managing your finances smarter!
