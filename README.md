

# 📦 ApnaBudget - Beta v0.1.0 (NUST Testing Release)

Welcome to the **Beta v0.1.0** release of **ApnaBudget: Empowering Your Financial Future Through Smart Budgeting** – specially crafted for beta testing in **NUST Islamabad**.

This release is part of our exclusive beta testing phase and may include bugs or partially implemented features. Your feedback is incredibly valuable and will directly influence the final app experience.

---

## 🔍 What’s New in v0.1.0

- 🔐 **Improved Login & Registration**
- 📩 **Enhanced SMS and Notification-based Transaction Fetching**
- 🧾 **Manual Transaction Entry with Validation**
- 🖼️ **Image-Based Transaction Input (Beta)**
- 🗂️ **Smarter Transaction Categorization**
- 📊 **Spending Summary with Visual Insights**
- 🎯 **Budget Creation & Tracking (Experimental)**
- ⚙️ **UI Enhancements & Performance Optimizations**

---

## 📱 Installation Guide

1. Download the APK from our [GitHub Release Page](https://github.com/Apna-Budget/apnabudget-android-app/releases)].
2. Enable “Install from Unknown Sources” in your phone settings.
3. Open the APK file and install it.
4. Launch **ApnaBudget** and begin exploring!
